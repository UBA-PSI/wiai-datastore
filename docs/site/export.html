Export a vault

Download everything in your vault, decrypted, as a ZIP file. This works for every app of the WIAI Datastore, also when the app itself is gone. You need your access ID (or key file) and your passphrase. The server only ever sees encrypted data.

It fills in the app ID and the access ID. A key file holds no secret.

On your access sheet in brackets after the app name, for example notenrechner-k7m2a9.

You can also enter it in the next window. You enter your passphrase there, never on this page.

Keep this page for later

Save this page as an HTML file (browser menu, "Save page as"). The saved file works from your disk as well: it loads the library from the faculty server and checks its checksum, so you need a connection but no other file. Do not create a new vault here.
